## 1. 控制和观察项

控制：

| 操作 | 按键 |
|---|---|
| 转舵 | `A / D` |
| 收帆 / 放帆 | `↑ / ↓` |
| 压舷 / 移动重心 | `← / →` |
| 稳向板放下 / 抬起 | `W / S` |
| 缩放 | 鼠标滚轮或右侧缩放条 |

每个场景尽量记录这些观察项：

| 观察项 | 记录重点 |
|---|---|
| 船速 | 是否加速、掉速、停滞 |
| 航向 | 是否能稳定保持，是否容易穿过风眼 |
| 帆状态 | 是否能看出 attached / luffing / stalled / backwinded |
| 舵效 | 小舵角和大舵角是否差异明显 |
| 侧滑 | 稳向板变化后是否明显 |
| 横倾 | 压舷方向对 heel 是否合理 |
| 教学解释 | 屏幕是否解释了为什么发生这个现象 |

## 2. 严重程度标准

| 等级 | 含义 |
|---|---|
| 高 | 会误导初学者理解真实帆船，必须优先改 |
| 中 | 不够真实，但还能作为原型继续教学 |
| 低 | 细节问题或显示问题，后续 polish |
| 争议 | 帆船同学之间意见不一致，需要更多人试玩 |
